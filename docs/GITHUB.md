# Đưa repo lên GitHub

Tên đề xuất: `vietnamese-image-captioning-ktvic`. Chế độ **private** theo yêu cầu.
Repo local này được tạo từ bản chọn lọc ngày 09/11/2026, không giữ giả lịch sử sáu tuần.

Sau khi kết nối GitHub, tạo repo riêng tư rỗng (không sinh thêm README/license),
rồi từ thư mục `week1_repo` thực hiện:

```powershell
git remote add origin https://github.com/TAI_KHOAN/vietnamese-image-captioning-ktvic.git
git push -u origin main
```

Thay `TAI_KHOAN` bằng tài khoản thực tế, không chạy nguyên placeholder.
Không dùng `--force`. Nếu repo cùng tên đã tồn tại, kiểm tra trước khi dùng.
Không đặt token trong URL hay lưu vào tệp. Dùng trình quản lý đăng nhập GitHub.

Mời thành viên còn lại và giảng viên trong Settings → Collaborators sau khi
biết chính xác tài khoản. Chưa có tài khoản giảng viên nên không tự gửi lời mời.
Tạo các issue từ kế hoạch tuần trong PLAN.md khi cả hai thống nhất phân công.
